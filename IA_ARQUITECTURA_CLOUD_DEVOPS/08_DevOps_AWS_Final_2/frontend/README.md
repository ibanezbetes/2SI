# Mantenigram Frontend

Frontend en React Native (Expo) para la aplicación Mantenigram.

## Configuración

1.  Instalar dependencias:
    ```bash
    npm install
    ```

## Ejecución

Para iniciar la aplicación en desarrollo:

```bash
npm start
```

Esto abrirá el servidor de desarrollo de Expo. Puedes escanear el código QR con la app Expo Go en tu dispositivo móvil o ejecutar en un emulador.

## Estructura

- `src/screens`: Pantallas de la aplicación.
- `src/components`: Componentes reutilizables.
- `src/services`: Servicios de API.
- `src/navigation`: Configuración de navegación.
